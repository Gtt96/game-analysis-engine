# 赛事五引擎分析器

一个基于历史赛事数据的概率建模与回测框架，支持多引擎融合、错题本校准和阈值自适应优化。

## 项目简介

本项目是一个独立的体育赛事数据分析工具，通过整合多个维度的历史数据，构建概率模型并对赛事结果进行建模分析。核心特点：

- **多引擎融合**：5 个独立分析引擎并行输出，综合判断
- **错题本机制**：持续积累历史案例，支持最近邻匹配与校准
- **阈值自适应**：基于 ROC / 约登指数自动优化判定阈值
- **完整回测框架**：支持基准对比、AUC 评估和版本迭代追踪
- **零外部依赖**：纯标准库实现，无需安装第三方包

> 本项目仅用于体育赛事数据分析与概率建模研究。

## 技术栈

- Python 3.6+
- 标准库：json / os / datetime / math / re / collections / statistics / bisect / shutil / traceback / inspect
- 无第三方依赖

## 快速开始

### 运行程序

```bash
python 赛事五引擎分析器.py
```

程序启动后进入交互式菜单，支持以下功能：

1. **开始分析** — 输入赛事数据，五引擎并行输出综合判断
2. **错题本全量回测** — 对历史错题本数据进行回测评估
3. **智能复盘报告** — 自动生成复盘分析
4. **更新错题本条目** — 增量更新历史数据
5. **共振批量测试** — 批量验证共振信号
6. **比赛相似度对比** — Top-K 相似案例检索
7. **查看错题本列表** — 浏览历史数据
8. **批量复盘测试** — 批量回测
9. **按编号查看分析** — 查看特定场次分析
10. **信心区间命中率报告** — 信心分档统计
11. **冷门最近邻阈值回测** — 精确率/召回率评估
12. **热门信心校准回测** — 分档命中率/Brier 评分
13. **信心分档低概率结果率校准** — 市场信心与相似度联合校准

### 数据录入

程序内置了示例错题本数据（`ERROR_BOOK` 列表），可直接运行体验。如需使用自己的数据，编辑源码中的 `ERROR_BOOK` 列表即可，每条数据包含以下字段：

| 字段 | 说明 |
|---|---|
| handicap | 让分面板数值 |
| jc_win / jc_draw / jc_lose | 概率面板（主/平/客） |
| rq_win / rq_draw / rq_lose | 让分概率面板（主/平/客） |
| avg_win / avg_draw / avg_lose | 平均概率面板（主/平/客） |
| shenjia | 身价对比描述 |
| real_result | 实际赛果（胜/平/负） |
| real_score | 实际比分 |
